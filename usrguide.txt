PyCalc User's Guide
By Wyatt Fullerton
What PyCalc does
PyCalc is a menu-driven Python calculator with 13 operations. It runs once per launch: pick an operation, enter your numbers, read the answer, and the program ends. To do another calculation, run it again.
Running it
• Run main.py with python3 main.py (on Windows: python main.py), or paste it into the Programiz online compiler(or any other) and press Run.
• You need Python 3.8 or newer. No extra packages are needed.
The menu
When PyCalc starts it asks:
Enter Operation(sum=1, multiply=2, divide=3, ... ratio simplifier=13):
Type a number from 1 to 13 and press Enter. Anything outside that range ends the program with "Unknown operator".

Operation details
3. Divide
Shows the answer rounded to 2 decimal places, then asks More?. Type T or t to also see the full-precision answer. Anything else finishes.
7. Divide with remainder
Gives the whole-number quotient, the letter r, then the remainder. 17 and 5 gives 3r2.
8. Factorial
Whole numbers only, and no negatives. A decimal like 2.5 causes an error. Very large inputs (like 100000) take a long time.
9. Exponential growth
Applies the same operation to a number over and over, printing every step. It asks three questions:
1. Starting number: for example 2
2. Operation: an operator and a number, like * 3. Type it without brackets. The [* 7] in the prompt is just an example. The space is optional, so *3 and **2 also work.
3. How many times: for example 4
Result for 2, * 3, 4:
2.0
6.0
18.0
54.0
162.0
Rules for the modifier:
• Allowed operators: +, -, *, /, **
• No letters and no brackets
• 10 characters or fewer
Numbers grow fast with **. Starting at 200 with **2, the values pass 10^300 after about 8 repeats and the program stops with an overflow error.

11. Percent of
The percent goes first, then the amount. 20 and 50 means "20% of 50" and gives 10.0.

Special Operations
Special operations are operations 6-13. These operations are called special because(With the expectation of 12, converter) they would not be found on any other calculator, are more complex, and most don't use "Enter 1st number:" and "Enter 2nd number:".

None of these errors change anything on your computer. Restarting the program is always the fix.
Good to know
• Precision: PyCalc uses regular decimal numbers, which hold about 15 to 16 digits. Anything past that is rounded when you type it in.
• Operation 9 uses eval: it runs the modifier you type as Python math. The letter, bracket, and length checks keep that safe for personal use, but don't copy this part into something that other people can type into, like a website or a bot.
• Output format: most answers print with a .0 (like 7.0) because inputs are read as decimals.
Quick start
1. Run the program.
2. Type 1 for sum and press Enter.
3. Enter 4, then 3.
4. Read 7.0.
